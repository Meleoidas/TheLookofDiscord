# The Look of Discord

An old attempt of recreating Discord's look in browser using only pure HTML and CSS (NO JS).

This might be perhaps the worst CSS ever written by a human being, but it's functional. I tried to get as close as possible to the actual look. Everything was written by a human hand, and no copy pasting (besides the SVGs obviously) was involved.

It was initially meant to become a personal site with multiple working servers to access. It remained unfinished after Discord completely changed its appearance.

> [!WARNING]
It's intentionally not designed for mobile, the sizing won't work properly.
